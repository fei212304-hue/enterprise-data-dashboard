## 一之一、免安装网页版（最适合新手，无需命令行）

如果你不想装 Python、不想开命令行，只想「上传表格 → 看图表」，用这一个文件就够了：

1. 双击 `dashboard-web.html`（用 Chrome 打开）
2. 点击上传区域，选你的 `.xlsx` / `.xls` / `.csv`
3. 工具**自动**识别字段（数值 / 分类 / 编号），你只需在「主指标」下拉里选想分析的核心数字列，点「生成看板」

它会在浏览器本地完成所有计算，**数据不会上传到任何服务器**；图表库与解析库都已内嵌，因此**断网也能用**。每张图右上角「保存图片」可导出 2 倍高清 PNG；「下载清洗后数据」可导出清洗后的 CSV。

**上传即自动清洗，无需手动设置任何参数**（算法完全由你上传的数据自动决定）：

| 脏数据类型 | 自动处理方式 |
|---|---|
| 重复行 | 整行内容完全相同的视为重复，**只保留首次出现**，其余删除 |
| 缺失值 | 数值列的缺失格用**该列中位数**填补（中位数不受极端值影响，比均值更稳健） |
| 异常值 | 对主指标用 **IQR 1.5× 法则**（正常区间 = Q1−1.5×IQR ~ Q3+1.5×IQR）自动剔除 |

页面顶部会显示一张「数据清洗报告」卡片，写明**原始多少行、删除多少重复行、填补多少个缺失值（哪几列）、剔除多少异常值（正常区间是多少）**，所有图表都基于清洗后的数据绘制——处理过程完全透明，不是偷偷改数据。

**第 1 张图（主指标分布）会按样本量自动换画法**：数据 ≥ 20 行时画直方图，分箱宽度按 Freedman-Diaconis 规则自适应、频数刻度自动取整；不足 20 行时改画「每条数据一行」的阶梯点图——因为只有 6 行数据时，直方图会被切成一两根巨型柱子，什么也看不出来。图上方始终标注 n、均值、中位数，并用黄色虚线（中位数）和红色点线（均值）画在图上。

> 与 `tools/build_dashboard.py` 的区别：网页版**零安装、零命令**，适合临时看一眼数据；Python 版适合批量 / 自动化生成、可定制更多图表类型。两者自动识别字段的逻辑一致。

## 二、通用看板生成器

上面的看板最初是「为这一份数据量身定制」的。为了方便后续复用，已把它重构成**通用工具**：

```
python build_dashboard.py 你的数据.xlsx
```

一条命令，自动生成一份同风格的可交互看板 HTML。它会**自动**：

- 识别字段角色 —— 数值字段做均值 / 分布 / 相关系数；分类字段（取值 ≤ 12 种）做成筛选标签，最多 4 个；**编号类字段（ID、序号、单号）自动剔除**，不参与计算
- 做基础清洗 —— 数值列的缺失值用**列中位数**填补，分类型缺失值标为「未填写」；重复行只统计**不删除**
- 挑选主指标 —— 优先匹配名称含「营业额 / 销售额 / 金额 / 利润 / 营收」的字段，也可用 `--main 列名` 手动指定
- 生成 9～11 张图 —— 分类均值对比、占比环图、分布直方图、箱线图、散点图、相关系数条形图、相关性热力图、缺失值分布、TOP12 排行榜
- 生成交互 —— 顶部筛选标签、每张图「保存图片」（3 倍高清 PNG）、一键导出全部、KPI 的「▲ 高于全量 x.x%」对比

**完整例子：**

```bash
python build_dashboard.py "销售数据.xlsx" \
       --sheet 2024年 --title "2024 年度经营看板" \
       --main 销售额 --filters 城市 品类 -o 年度看板.html
```

支持 `.xlsx` / `.xls` / `.csv`，中文路径与中文列名均已实测通过。详细说明见 [`tools/使用说明.md`](tools/使用说明.md)。

## 三、数据来源与引用

**原始数据文件**：`企业数据分析样本（1000-缺失值、重复值、异常值演示）.xlsx`

**来源**：课程《大数据统计》第 3 章「描述统计与清洗」课堂练习发放的教学样本

**数据性质**：该文件为**教学演示用模拟数据**。文件名本身已注明其包含人为植入的缺失值、重复值与异常值，专供练习数据清洗方法使用。

### 声明

1. 本仓库**不包含**原始数据文件（属课程材料，未获授权公开分发）。如需复现分析，请使用课堂发放的原始文件。
2. 原始文件在整个分析过程中**未做任何修改**，所有清洗结果均输出为独立文件。
3. 相关性分析显示：本样本中除「市场占有率」（r = +0.572）和「员工规模」（r = +0.448）外，其余 9 个指标与年营业额的相关系数绝对值均小于 0.05，呈相互独立状态，**符合随机生成数据的典型特征**。因此本项目的分析结论**仅用于演示统计方法，不构成任何真实商业洞察**。

## 四、数据概况

- 样本量：**1010 家企业**（文件名标注 1000 条，实际 1010 行）
- 字段数：**17 个**（12 个数值字段 + 4 个分类字段 + 1 个主键）
- 缺失值：**987 个单元格**（占 5.7%），分散在 10 个数值字段，各字段缺失率 8.7%–11.4%
- 完全重复行：**0 条**（经「全字段比对」「企业ID 比对」「去 ID 后比对」三种口径检查）
- 异常值：**120 个值**

### 清洗处理记录

| 问题类型 | 数量 | 处理方式 |
| --- | --- | --- |
| 数值字段缺失 | 987 个单元格 | 按行业类型分组取**中位数**填补 |
| 完全重复行 | 0 条 | 无需处理 |
| 年营业额为负 | 20 条 | 判定为录入错误，置空后按分组中位数填补 |
| 资产负债率 > 100% | 50 条 | 判定为逻辑错误，置空后填补 |
| 市场占有率 > 100% | 50 条 | 判定为逻辑错误，缩尾至 30% 上限 |
| 客户满意度 4–5 分、ESG 7–9 分 | 被 IQR 判为统计异常 | **保留不动**：取值在量表与合理范围内，属真实优质企业，删除会损失信息 |

清洗前后均值变化最大的是市场占有率（−38.3%）、员工规模（−25.7%）、年营业额（−23.8%）。
