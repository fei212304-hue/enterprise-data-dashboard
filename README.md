## 二、数据来源与引用

**原始数据文件**：`企业数据分析样本（1000-缺失值、重复值、异常值演示）.xlsx`

**来源**：课程《大数据统计》第 3 章「描述统计与清洗」课堂练习发放的教学样本

**数据性质**：该文件为**教学演示用模拟数据**。文件名本身已注明其包含人为植入的缺失值、重复值与异常值，专供练习数据清洗方法使用。

### 声明

1. 本仓库**不包含**原始数据文件（属课程材料，未获授权公开分发）。如需复现分析，请使用课堂发放的原始文件。
2. 原始文件在整个分析过程中**未做任何修改**，所有清洗结果均输出为独立文件。
3. 相关性分析显示：本样本中除「市场占有率」（r = +0.572）和「员工规模」（r = +0.448）外，其余 9 个指标与年营业额的相关系数绝对值均小于 0.05，呈相互独立状态，**符合随机生成数据的典型特征**。因此本项目的分析结论**仅用于演示统计方法，不构成任何真实商业洞察**。

## 三、数据概况

- 样本量：**1010 家企业**（文件名标注 1000 条，实际 1010 行）
- 字段数：**17 个**（12 个数值字段 + 4 个分类字段 + 1 个主键）
- 缺失值：**987 个单元格**（占 5.7%），分散在 10 个数值字段，各字段缺失率 8.7%–11.4%
- 完全重复行：**0 条**（经「全字段比对」「企业ID 比对」「去 ID 后比对」三种口径检查）
- 异常值：**120 个值**

### 清洗处理记录

| 问题类型 | 数量 | 处理方式 |
| --- | --- | --- |
| 数值字段缺失 | 987 个单元格 | 按行业类型分组取**中位数**填补 |
| 完全重复行 | 0 条 | 无需处理 |
| 年营业额为负 | 20 条 | 判定为录入错误，置空后按分组中位数填补 |
| 资产负债率 > 100% | 50 条 | 判定为逻辑错误，置空后填补 |
| 市场占有率 > 100% | 50 条 | 判定为逻辑错误，缩尾至 30% 上限 |
| 客户满意度 4–5 分、ESG 7–9 分 | 被 IQR 判为统计异常 | **保留不动**：取值在量表与合理范围内，属真实优质企业，删除会损失信息 |

清洗前后均值变化最大的是市场占有率（−38.3%）、员工规模（−25.7%）、年营业额（−23.8%）。
