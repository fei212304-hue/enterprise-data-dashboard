# 通用数据看板生成器 · 使用说明

把任意一份 Excel 或 CSV，**一键变成**一份可以点着筛选、每张图都能存成 PNG 的交互式看板。

不需要懂编程，照着下面做就行。

---

## 一、最省事的用法

### 第 1 步：打开命令行

- 按 `Win` 键，输入 `PowerShell`，回车，打开蓝色窗口

### 第 2 步：进入**你自己的 Python 环境**

> 这一步是为了用到装好的 pandas / plotly。**每次新开窗口都要做一次**。

```
D:\workbuddy\streamlit-sales-dashboard\.venv\Scripts\Activate.ps1
```

回车后提示符前面会多出 `(.venv)`，像这样：

```
(.venv) PS C:\Users\菲>
```

> 如果提示"禁止运行脚本"，先执行一次（只要一次，以后都不用）：
> `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`

### 第 3 步：生成看板

一条命令，把最后那段换成你的数据文件路径：

```
python D:\workbuddy\enterprise-data-dashboard\tools\build_dashboard.py "你的数据文件.xlsx"
```

**回车后你会看到**：

```
看板生成完成
  输出文件 : D:\...\你的数据文件_看板.html （3.89 MB）
  数据量   : 1010 行 × 17 列
  主指标   : 年营业额
  数值字段 : 12 个 —— 员工规模、年营业额、利润率...
  分类字段 : 4 个 —— 产品质量等级、企业性质、行业类型、所在地区
  筛选器   : 产品质量等级、企业性质、行业类型、所在地区
  缺失填补 : 987 个    完全重复行：0 条
```

**然后在你的数据文件旁边，会多出一个 `_看板.html` 文件，双击用 Chrome 打开就是看板。**

> **路径里有空格或中文？一定要用英文双引号包起来**，比如
> `python build_dashboard.py "D:\我的数据\第3章 样本.xlsx"`

## 二、稍微进阶一点的用法

在命令后面加参数可以微调：

| 想做什么 | 加这个参数 | 例子 |
|---|---|---|
| 自定义输出文件名 | `-o 文件名` | `-o 第三周的分析.html` |
| 自定义看板标题 | `--title 标题` | `--title "2026 上半年经营看板"` |
| 指定主指标（最重要的那个数） | `--main 列名` | `--main 年营业额` |
| 指定哪些字段做筛选器 | `--filters 列1 列2` | `--filters 行业类型 所在地区` |
| 读 Excel 里某个工作表 | `--sheet 工作表名` | `--sheet 2024年` |
| CSV 打开是乱码 | `--encoding 编码` | `--encoding gbk` |

**完整例子：**

```
python build_dashboard.py "销售数据.xlsx" --sheet 2024年 --title "2024年度经营看板" --main 销售额 --filters 城市 品类 -o 年度看板.html
```

## 三、它会自动帮你做什么

不用你告诉它每个字段是什么，它会自己判断：

**自动识别字段角色**
- **数值字段**（能做平均数的）→ 做均值、分布、相关系数
- **分类字段**（取值不多于 12 种的文本）→ 做成筛选标签，最多 4 个
- **编号类字段**（企业ID、序号、单号这种）→ **自动剔除**，不参与计算（算这些字段的平均数没意义）

**自动清洗**
- 数值列有空格 → 用该列**中位数**填补
- 分类列有空格 → 标成「未填写」
- 完全重复的行 → 统计出来告诉你，**但不会删**（要不要删你自己决定）

**自动生成这些图**（数量随数据而定，通常是 9～11 张）：
1. 各分类的主指标均值对比（横向条形图）
2. 分类构成占比（环图）
3. 主指标分布直方图（带均值线）
4. 按分类的主指标箱线图（看异常值）
5. 主指标 × 最相关字段的散点图
6. 各数值字段与主指标的相关系数条形图
7. 数值字段相关性矩阵热力图
8. 原始缺失值分布（如果数据本来有缺失）
9. 主指标 TOP12 排行榜表格

**自动生成这些交互**
- 顶部筛选标签：点一下取消某类，所有图和数据立即重算
- 每张图右上角「保存图片」：存成 3 倍高清 PNG
- 「一键导出全部图片」：一次把所有图存下来
- KPI 卡片下方显示「▲ 高于全量 x.x%」，筛选后才知道是高是低

## 四、常见问题

**Q：双击 html 文件没反应 / 打开是空白？**
用 Chrome 打开试试：右键文件 → 打开方式 → Google Chrome。

**Q：提示"找不到文件"？**
把文件用鼠标拖到 PowerShell 窗口里，它会自动填好正确路径。

**Q：提示"不是内部或外部命令"？**
说明第二步的 `(.venv)` 激活没成功，或者 `python` 没识别到。重新执行第二步，确认提示符前面有 `(.venv)`。

**Q：数据文件放在中文路径的文件夹里，会不会有问题？**
完全支持，路径两边加英文双引号就行。（这一版已经专门测试过中文路径和中文列名。）

**Q：数据量几万行会不会很慢？**
几万行没问题。超过 10 万行，生成的 HTML 会很大（因为数据要内嵌进去才能离线用），打开会慢。这种情况建议先抽样再分析。

**Q：能不能按我自己的想法加图？**
可以，把 `build_dashboard.py` 给我，告诉你想加什么图，我来改。

## 五、依赖说明

脚本需要（都装在 `(.venv)` 里了）：

```
pandas      # 读表格、算统计
numpy       # 数值计算
plotly      # 提供 plotly.min.js（会自动内嵌到 HTML，所以离线也能看）
openpyxl    # 读取 xlsx
```

如果换台电脑缺这些，装一次即可：

```
pip install pandas numpy plotly openpyxl -i https://pypi.tuna.tsinghua.edu.cn/simple
```
